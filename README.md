# Movie Explorer

A modern React + TypeScript web app for browsing movies and actors using the TMDB API.

## Tech Stack
- React 18 + TypeScript  
- Redux Toolkit  
- React Router v6  
- Tailwind CSS (dark/light theme)  
- Axios  
- Vite  

## Features
- Movie search and filtering  
- Detailed movie and actor pages  
- Favorites - movies & actors (saved in localStorage)  
- Responsive design + dark/light mode

git clone https://github.com/yourusername/movie-explorer.git
